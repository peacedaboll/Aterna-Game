# Aterna

2D-игра в жанре Metroidvania на Unity. Проект находится на стадии раннего прототипа.

| Параметр | Значение |
|---|---|
| Движок | Unity 2022.3.62f1 |
| Тип | 2D |
| Целевая платформа | Windows |
| Статус | Прототип |
| Сборка | Разработчик сообщил об успешном создании Windows-билда 11.10.2026; запуск и полный smoke-тест ещё требуется зафиксировать |

## Что реализовано

- Главное меню с кнопками Start и Exit.
- Частично реализованное окно настроек.
- Выбор персонажа: доступен один персонаж, секретный слот запланирован.
- Карта с узлами выбора локаций.
- Управление персонажем: движение, прыжок и анимация бега.
- Тренировочная сцена.
- Сцены локаций Arama, Batava и CTown.
- Сцена Load Scene с обратным отсчётом перед переходом на Map.

## Известные ограничения

- Полноценное поведение врагов (ИИ, здоровье и урон) пока не реализовано по ранее предоставленному описанию.
- Меню настроек требует проверки и доработки.
- Секретный персонаж ещё не реализован.
- Успешное создание билда подтверждено разработчиком, но запуск и полный smoke-тест должны быть записаны отдельно.
- Совместимость с разными версиями Windows, разрешениями и аппаратными конфигурациями ещё не подтверждена.

## Как открыть проект

1. Установите Unity Hub и Unity Editor версии 2022.3.62f1.
2. Склонируйте репозиторий: https://github.com/peacedaboll/Aterna-Game.git
3. В Unity Hub выберите Add project from disk и укажите папку проекта.
4. Откройте Assets/Scenes/Menu.unity и нажмите Play.

Папка Library создаётся Unity локально и не хранится в репозитории. Первый запуск может занять несколько минут.

- Assets/ — сцены, скрипты, изображения и анимации.
- Packages/ — зависимости Unity.
- ProjectSettings/ — настройки проекта и список сцен для сборки.
- docs/ — документация по техническому долгу, тестированию и совместимости.
- CHANGELOG.md — история изменений.
- README.md — описание проекта.
