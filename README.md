# Aterna

2D-игра в жанре Metroidvania на Unity. Проект находится на стадии раннего прототипа.
|  |  |
|---|---|
| **Движок** | Unity 2022.3.62f1 |
| **Тип** | 2D |
| **Целевая платформа** | Windows |
| **Статус** | Прототип, версия 0.1.0 |

## Что реализовано

- Главное меню (Start, Exit, окно настроек - частично)
- Выбор персонажа (доступен один персонаж, слот секретного персонажа запланирован)
- Выбор локации (три узла)
- Управление персонажем: движение и прыжок, анимация бега
- Тренировочный уровень

## Что пока не реализовано

- ИИ, здоровье и урон врагов (враг - физическое препятствие)
- Полноценное меню настроек
- Секретный персонаж
- Подтверждённая Windows-сборка (см. [аудит техдолга](docs/tech-debt-audit.md), TD-01)

## Как открыть проект

1. Установите Unity Hub и редактор **Unity 2022.3.62f1**.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/peacedaboll/Aterna-Game.git
   ```
3. В Unity Hub: **Add → Add project from disk** и выберите папку проекта.
4. Откройте сцену `Assets/Scenes/Menu.unity` и нажмите Play.

> Папка `Library/` не хранится в репозитории и создаётся Unity при первом открытии. Первый запуск может занять несколько минут.

## Управление

| Действие | Клавиши |
|---|---|
| Движение влево / вправо | `A` / `D` или стрелки (ось `Horizontal`) |
