# Changelog

Все значимые изменения проекта Aterna фиксируются в этом файле. В журнал вносятся только подтверждённые изменения; непроверенные исправления не записываются как выполненные.

## [Unreleased] — 11.10.2026 — Успешная сборка и актуализация документации

### Changed
- Обновлён аудит технического долга по текущему состоянию репозитория.
- Уточнены реальные имена сцен: Menu, ChoiseCharacter, Traning, Map, Load Scene, Arama, Batava, CTown.
- Уточнено состояние Build Settings: восемь перечисленных сцен включены в сборку.
- Обновлены стратегия тестирования и матрица совместимости.
- README уточнён в части статуса Windows-сборки.

### Fixed
- По сообщению разработчика, после решения проблемы с OneDrive Windows-билд удалось успешно создать. Первоначальная причина сбоя Bee не доказана отдельно.
- Ошибка сборки больше не описывается как текущий блокер; запуск и smoke-тест билда ещё требуется задокументировать.

### Known issues
- Runtime-проверка собранного приложения ещё не записана в документации.
- Требуется проверить основной маршрут Menu → ChoiseCharacter → Traning.
- Требуется проверить карту Map, узлы Arama/Batava/CTown и логику Load Scene.
- Настройки ранее были частично реализованы; актуальное состояние нужно перепроверить.
- По ранее предоставленному описанию, у врага нет ИИ, здоровья и системы урона.
- Доступен один персонаж.

### Verification
- Репозиторий и текущие C#-скрипты просмотрены через GitHub.
- Build Settings содержит восемь включённых сцен.
- Успешное создание Windows-билда подтверждено сообщением разработчика.
- Запуск standalone и тесты совместимости не считаются пройденными до фактического прогона.

## [0.1.0] — 10.10.2026 — Аудит прототипа

### Added
- Проект загружен в GitHub-репозиторий, настроены .gitignore и .gitattributes для Unity.
- Зафиксирован контекст проекта и предварительный технический долг.
- Созданы стратегия тестирования, ручные чек-листы и матрица совместимости.
- Добавлены README.md и CHANGELOG.md.

### Known issues
- На момент первоначального аудита Windows-сборка завершалась ошибкой удаления каталога Bee.
- Ранее наблюдалась зацикленная анимация загрузки.
- Настройки реализованы не полностью.
- У врага нет ИИ, здоровья и системы урона.
- Доступен один персонаж.

### Verification
- Первоначальный аудит был основан на описании проекта и логе сборки.
- Успешная сборка на дату первоначального аудита не была подтверждена.
