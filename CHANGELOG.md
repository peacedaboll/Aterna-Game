# Changelog

Все значимые изменения проекта Aterna фиксируются в этом файле. В журнал вносятся только подтверждённые изменения; непроверенные исправления не записываются как выполненные.

## [Unreleased] — 18.10.2026 — Начало реализации меню настроек

### In progress
- В сцене меню подготовлена структура `SettingsMenu` с элементами `ResolutionDropdown`, `WindowToggle`, `AudioSlider`, `LaguageDropdown`, `ExitSettings` и `ConfirmationPanel`.
- Начата настройка `SettingsMenuController` для связывания UI-элементов и обработки выхода из меню настроек.
- Подготовлен кодовый вариант системы настроек на основе `PlayerPrefs`: разрешение экрана, оконный режим, общая громкость и язык (русский/английский).
- Подготовлен кодовый вариант подтверждения изменений с действиями «Да» (применить и сохранить), «Нет» (выйти без сохранения) и «Отмена» (продолжить редактирование).
- Подготовлен вариант компонента `LocalizedText` для перевода назначенных UI-текстов на русский и английский языки, а также `SettingsBootstrap` для загрузки сохранённых настроек при запуске.

### Known issues
- В Unity Console появляется ошибка `SettingsMenuController: назначь все четыре элемента настроек в Inspector`: ссылки на четыре UI-компонента ещё не назначены в Inspector.
- На момент последней проверки `SettingsMenuController` находился на объекте `ExitSettings`; перенос контроллера на родительский `SettingsMenu` и перепривязка `On Click()` предложены, но выполнение ещё не подтверждено.
- Обработчики кнопок подтверждения, применение/сохранение значений, восстановление после перезапуска и локализация пока не проверены в Unity.
- Работа настроек и Windows-сборка после этих изменений не протестированы.

### Verification
- В Unity Editor проверена иерархия сцены меню по предоставленному скриншоту.
- Подтверждено наличие UI-объектов для четырёх параметров и `ConfirmationPanel`.
- Подтверждена ошибка незаполненных ссылок в `SettingsMenuController`.
- Успешное выполнение полного сценария настроек не подтверждено.

## [0.3.0] — 16.10.2026 — Отложенная загрузка выбранного уровня

### Changed
- Кнопка Arama передаёт имя выбранной сцены общему загрузчику.
- Load Scene сохраняет выбранный уровень, показывает анимацию загрузки и через 10 секунд пытается открыть выбранную сцену.
- Если текстовое поле таймера не назначено, отсчёт и переход всё равно продолжаются.
- Добавлена проверка, доступна ли целевая сцена в Build Settings.

### Verification
- Изменения скриптов объединены в `main` через pull request #1.
- Проверка в Unity Editor и Windows-сборке ещё не выполнена.

## [0.2.0] — 15.10.2026 — Проверка Windows-билда

### Changed
- Обновлён аудит технического долга по текущему состоянию репозитория и описанию фактического запуска билда.
- Уточнено состояние Build Settings: восемь перечисленных сцен включены в сборку.
- Обновлены стратегия тестирования и матрица совместимости с результатами.

### Fixed
- Windows-билд создаётся без ошибок и запускается. Первоначальный сбой сборки наблюдался во время операций OneDrive; успешный билд впоследствии был получен.

### Known issues
- После выбора единственного доступного уровня Arama экран загрузки с анимацией зацикливается и переход не завершается; основной игровой маршрут заблокирован.
- Меню настроек открывается, но параметры пока не меняются; работает только кнопка выхода.
- Первый «враг» пока представлен камнем-препятствием: на него можно встать, он не двигается и не взаимодействует с игроком.
- Доступен только один персонаж.

### Verification
- Репозиторий и текущие C#-скрипты просмотрены через GitHub.
- Build Settings содержит восемь включённых сцен.
- Windows-билд создаётся без ошибок и запускается.
- Проверены главное меню, Start, выбор персонажа, тестовый уровень, движение, прыжок, 10-секундный таймер и выбор Arama.
- Smoke-тест не пройден: после выбора Arama экран загрузки зацикливается. Причина - нет самого уровня "Arama".
- Batava, CTown, разные разрешения и другие ОС не проверены.
