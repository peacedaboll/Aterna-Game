# Аудит технического долга

**Проект:** Aterna — 2D Metroidvania  
**Движок:** Unity 2022.3.62f1  
**Версия документа:** 0.2  
**Дата обновления:** 11.10.2026  
**Статус:** актуализирован по текущему GitHub main и сообщению разработчика об успешном создании Windows-билда

> Границы достоверности: конфигурацию сцен и код можно проверить по репозиторию. Успешное создание билда подтверждено разработчиком, но запуск билда и прохождение всех игровых сценариев независимо не проверялись. Поэтому runtime-проверки не отмечены как пройденные.

## 1. Контекст текущей версии

### 1.1. Основные сцены

Сцены, найденные в Assets/Scenes и включённые в ProjectSettings/EditorBuildSettings.asset:

| Сцена | Назначение / наблюдение |
|---|---|
| Menu | Главное меню |
| ChoiseCharacter | Выбор персонажа |
| Traning | Тренировочный уровень |
| Map | Карта с узлами выбора локаций |
| Load Scene | Экран загрузки с таймером |
| Arama | Игровая локация |
| Batava | Игровая локация |
| CTown | Игровая локация |

Названия сохранены так, как они записаны в проекте. В частности, ChoiseCharacter и Traning написаны именно так; не переименовывать их без одновременного обновления ссылок и проверок.

### 1.2. Основные скрипты

| Скрипт | Текущее поведение по коду |
|---|---|
| Assets/Scripts/BeginStart.cs | Загружает сцену ChoiseCharacter |
| Assets/Scripts/ChoiseMainPlayer.cs | Загружает сцену Traning |
| Assets/Scripts/AramaMap.cs | Загружает сцену Load Scene |
| Assets/Scripts/SceneDelayLoader.cs | Показывает обратный отсчёт и затем загружает Map |
| Assets/Scripts/ExitButton.cs | Вызывает Application.Quit; в Unity Editor останавливает Play Mode |
| Assets/Scripts/PlayerController.cs | Движение по Horizontal, прыжок по Space, Animator-параметр isRunning |

### 1.3. Текущая функциональная картина

| Подсистема | Что подтверждено по репозиторию / сообщению разработчика | Что ещё проверить в игре |
|---|---|---|
| Windows-билд | Разработчик сообщил, что билд успешно создан после решения проблемы с OneDrive | Запустить именно собранный файл и пройти smoke-тест |
| Build Settings | В список включены Menu, ChoiseCharacter, Traning, Map, Load Scene, Arama, Batava и CTown | Проверить переходы в билде |
| Главное меню | В Menu подключена кнопка, вызывающая BeginStart.PressStart | Проверить Start и Exit в билде |
| Выбор персонажа | В ChoiseCharacter подключён ChoiseMainPlayer.PressMainPlayer | Проверить фактический переход в Traning |
| Карта | Map содержит узлы/объекты для Arama, Batava и CTown; у Arama есть вызов AramaMap.AramaPress | Проверить все три узла и выяснить, как выбираются две другие локации |
| Загрузка | SceneDelayLoader отсчитывает 10 секунд и затем вызывает загрузку Map | Проверить, завершается ли загрузка и соответствует ли переход желаемому игровому циклу |
| Управление | PlayerController использует Rigidbody2D, Horizontal, Space и Animator | Проверить движение, прыжок, коллизии и анимацию |
| Настройки | Ранее разработчик сообщал о частично работающем меню настроек | Повторно проверить все видимые элементы |
| Враг | По ранее предоставленной информации — физическое препятствие без ИИ, здоровья и урона | Подтвердить, что состояние не изменилось |

## 2. Приоритеты

- **P0 — блокер:** не удаётся собрать/запустить игру или пройти критический сценарий.
- **P1 — высокий:** не работает важная функция основного игрового цикла.
- **P2 — средний:** ограничение допустимо в прототипе, если оно задокументировано.
- **P3 — низкий:** можно отложить до следующего этапа.

Решения:
- **Исправить сейчас** — до расширения функциональности.
- **Принять как риск** — оставить временно и явно зафиксировать.
- **Переписать позже** — после стабилизации прототипа.

## 3. Реестр технического долга

| ID | Проблема / временное решение | Риск | Приоритет | Решение / статус |
|---|---|---|---|---|
| TD-01 | Ранее сборка падала при удалении каталога Bee; теперь разработчик сообщает об успешном создании билда после решения проблемы с OneDrive | Причина прежнего сбоя документально не доказана; runtime ещё не подтверждён | P0 — блокер сборки снят по сообщению разработчика | **Перепроверить:** сохранить успешный билд, запустить его и зафиксировать конфигурацию |
| TD-02 | Сцены были описаны в старой документации неточно; актуальный Build Settings содержит восемь включённых сцен | Ошибочные имена в документации могут привести к неправильным изменениям проекта | P1 документации | **Исправлено в этом аудите:** использовать реальные имена сцен из проекта |
| TD-03 | Ранее сообщалось о зацикленной анимации загрузки; текущий SceneDelayLoader ждёт 10 секунд и загружает Map | Возможен неверный маршрут, если карта должна открываться до выбора локации или таймер не работает | P1 | **Проверить сейчас в билде:** таймер, переходы и все узлы карты |
| TD-04 | Меню настроек ранее работало частично | Видимые настройки могут ничего не менять | P1/P2 | Проверить; незавершённые элементы скрыть или обозначить |
| TD-05 | У врага нет ИИ, здоровья и системы урона (по ранее предоставленному описанию) | Полноценная боевая система отсутствует | P2 | Принять для прототипа; спроектировать позже |
| TD-06 | Доступен один персонаж; секретный слот запланирован | Ограниченный контент или пустой слот интерфейса | P2 | Принять для прототипа; не выдавать слот за готовую функцию |
| TD-07 | Управление использует старый Input Manager: Horizontal и Space | Другие устройства ввода и переназначение клавиш не подтверждены | P2 | Оставить для прототипа; пересмотреть при расширении управления |
| TD-08 | Состояние земли определяется столкновениями с объектами с тегом Ground | Ошибки тегов/коллайдеров могут нарушать прыжок | P1/P2 | Проверить на платформе, краях и боковых столкновениях; при необходимости заменить на ground check |
| TD-09 | Rigidbody2D получает компонент через GetComponent, Animator задан через Inspector, параметр isRunning — строкой | Отсутствующая ссылка может вызвать NullReferenceException | P1/P2 | Проверить Inspector и Console; добавить защитные проверки при рефакторинге |
| TD-10 | Имена сцен жёстко заданы строками; присутствуют исторические варианты написания Choise и Traning | Переименование сцены может сломать переход | P2 | Сейчас сверить все строки; централизовать имена позже |
| TD-11 | Нет фактических результатов проверки разных ОС, разрешений и железа | Нельзя заявлять широкую совместимость | P1 перед релизом | Заполнить матрицу реальными прогонами |
| TD-12 | Журнал изменений только начал вестись | Без обновлений теряется история разработки | P2 | Продолжать обновлять CHANGELOG.md при каждом значимом изменении |

## 4. Что исправлять сейчас, что принять, что переписать позже

### Исправить / проверить сейчас
1. Запустить собранный Windows-билд и пройти smoke-тест.
2. Проверить цепочку Menu → ChoiseCharacter → Traning.
3. Проверить Map → Load Scene → Map и определить ожидаемый смысл этого маршрута.
4. Проверить все три узла Map: Arama, Batava, CTown.
5. Проверить назначение Rigidbody2D, Animator и параметра isRunning.
6. Проверить теги Ground и возможность прыжка только после приземления.
7. Убедиться, что документация и changelog отражают актуальное состояние.

### Принять как риск на стадии прототипа
- Только один доступный персонаж.
- Неполное меню настроек, если незавершённые функции не выдаются за готовые.
- Отсутствие ИИ, здоровья и урона у врага.
- Управление только клавиатурой через текущую схему Input Manager.

### Переписать / реализовать позже
- Система ИИ, здоровья, урона и поведения врагов.
- Система выбора персонажей и секретный персонаж.
- Централизованная маршрутизация сцен вместо строковых имён.
- Более надёжная проверка земли, если появятся сложные платформы.
- Автоматизированные тесты для устойчивой игровой логики.

## 5. Критерии закрытия ключевых пунктов

- **TD-01:** билд запускается на машине разработчика; основной smoke-тест проходит; сохранены дата и параметры сборки.
- **TD-03:** переходы между картой, экраном загрузки и локациями воспроизводимы; нет зависания/неожиданного возврата.
- **TD-08:** прыжок работает с земли, не срабатывает повторно в воздухе и снова доступен после приземления.
- **TD-09:** ссылки назначены, параметр Animator существует, в Console нет связанных исключений.
- **TD-11:** каждая отмеченная как поддерживаемая конфигурация реально проверена.
- **TD-12:** значимые изменения отражаются в CHANGELOG.md.

## 6. Ограничения аудита

- Успешное создание билда подтверждено сообщением разработчика; сам файл здесь не запускался.
- Содержимое сцен и скриптов просмотрено в GitHub, но поведение UI/физики невозможно подтвердить одним чтением YAML и C#.
- Старые сообщения о частично работающих настройках и зацикленной загрузке нужно перепроверить в текущем билде.
- Статус «Не проверено» не означает, что функция не работает; он означает отсутствие фактического результата теста.
