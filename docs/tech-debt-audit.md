# Аудит технического долга

**Проект:** Aterna — 2D Metroidvania  
**Движок:** Unity 2022.3.62f1  
**Версия документа:** 0.2  
**Дата обновления:** 15.10.2026  
**Статус:** актуализирован по GitHub main и фактическому описанию запуска Windows-билда разработчиком

> P.s - Сборка создана без ошибок и запускается, но smoke-тест не пройден: после выбора Arama экран загрузки зацикливается.

## 1. Контекст текущей версии

### 1.1. Основные сцены

Сцены, найденные в Assets/Scenes и включённые в ProjectSettings/EditorBuildSettings.asset:

| Сцена | Назначение / наблюдение |
|---|---|
| Menu | Главное меню |
| ChoiseCharacter | Выбор персонажа |
| Traning | Тренировочный уровень |
| Map | Карта с узлами выбора локаций |
| Load Scene | Экран загрузки с таймером |
| Arama | Игровая локация |
| Batava | Игровая локация |
| CTown | Игровая локация |

Названия сохранены так, как они записаны в проекте. В частности, ChoiseCharacter и Traning написаны именно так; не переименовывать их без одновременного обновления ссылок и проверок.

## 2. Приоритеты

- **P0 — блокер:** не удаётся собрать/запустить игру или пройти критический сценарий.
- **P1 — высокий:** не работает важная функция основного игрового цикла.
- **P2 — средний:** ограничение допустимо в прототипе, если оно задокументировано.
- **P3 — низкий:** можно отложить до следующего этапа.

Решения:
- **Исправить сейчас** — до расширения функциональности.
- **Принять как риск** — оставить временно и явно зафиксировать.
- **Переписать позже** — после стабилизации прототипа.

## 3. Реестр технического долга

| ID | Проблема / временное решение | Риск | Приоритет | Решение / статус |
|---|---|---|---|---|
| TD-01 | Ранее сборка падала при удалении каталога Bee; теперь разработчик сообщает об успешном создании билда после решения проблемы с OneDrive | Причина прежнего сбоя документально не доказана; runtime ещё не подтверждён | P0 — блокер сборки снят по сообщению разработчика | **Перепроверить:** сохранить успешный билд, запустить его и зафиксировать конфигурацию |

| TD-06 | Доступен один персонаж; секретный слот запланирован | Ограниченный контент или пустой слот интерфейса | P2 | Принять для прототипа; не выдавать слот за готовую функцию |

## 4. Что исправлять сейчас, что принять, что переписать позже

### Исправить / проверить сейчас
1. Исправить зацикливание экрана загрузки после выбора Arama — это текущий блокер.
2. Проверить цепочку Menu → ChoiseCharacter → Traning; по сообщению разработчика она работает.
3. Проверить маршрут выбора уровня → Load Scene → Arama и подтвердить целевую сцену.
4. Проверить Batava и CTown отдельно; они не подтверждены в текущем пользовательском сценарии.
5. Проверить назначение Rigidbody2D, Animator и параметра isRunning.
6. Проверить теги Ground и возможность прыжка только после приземления.
7. Убедиться, что документация и changelog отражают актуальное состояние.

### Принять как риск на стадии прототипа
- Только один доступный персонаж.
- Неполное меню настроек, если незавершённые функции не выдаются за готовые.
- Отсутствие ИИ, здоровья и урона у врага.
- Управление только клавиатурой через текущую схему Input Manager.

### Переписать / реализовать позже
- Система ИИ, здоровья, урона и поведения врагов.
- Система выбора персонажей и секретный персонаж.
- Централизованная маршрутизация сцен вместо строковых имён.
- Более надёжная проверка земли, если появятся сложные платформы.
- Автоматизированные тесты для устойчивой игровой логики.

## 5. Критерии закрытия ключевых пунктов

- **TD-01:** билд запускается на машине разработчика; основной smoke-тест проходит; сохранены дата и параметры сборки.
- **TD-03:** переходы между картой, экраном загрузки и локациями воспроизводимы; нет зависания/неожиданного возврата.
- **TD-08:** прыжок работает с земли, не срабатывает повторно в воздухе и снова доступен после приземления.
- **TD-09:** ссылки назначены, параметр Animator существует, в Console нет связанных исключений.
- **TD-11:** каждая отмеченная как поддерживаемая конфигурация реально проверена.
- **TD-12:** значимые изменения отражаются в CHANGELOG.md.

## 6. Ограничения аудита

- Описание запуска и обнаруженного дефекта предоставлено разработчиком 15.10.2026; сам файл здесь не запускался независимо.
- Содержимое сцен и скриптов просмотрено в GitHub, но нельзя утверждать, что причина зацикливания уже найдена.
- Настройки и поведение камня подтверждены описанием текущего билда; другие локации не проверены.
- Статус «Не проверено» не означает, что функция не работает; он означает отсутствие фактического результата теста.
