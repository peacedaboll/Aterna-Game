## 1. Платформы

| Платформа | Статус | Решение |
|---|---|---|
| Windows standalone | Попытка сборки завершилась ошибкой | Приоритет: добиться успешной сборки (TD-01) |
| Unity Editor | Используется при разработке; полный прогон не подтверждён | Выполнить smoke- и интеграционные тесты |
| macOS | Не проверено, поддержка не заявлена | Не заявлять без отдельной проверки |
| Linux | Не проверено, поддержка не заявлена | Не заявлять без отдельной проверки |
| WebGL / браузеры | Поддержка не заявлена | Не включать в цели без отдельного решения |
