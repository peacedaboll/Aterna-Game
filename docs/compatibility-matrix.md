## 5. Правила статусов

- **Сборка создана** — Unity завершила Build без ошибки.
- **Пройдено** — приложение запустилось и согласованный набор тестов прошёл.
- **Не пройдено** — обнаружен воспроизводимый дефект.
- **Заблокировано** — тест невозможно выполнить из-за другой проблемы.
- **Не проверено** — фактический прогон не выполнялся или результат не записан.

Статус «Поддерживается» допустим только после успешного запуска билда и базового smoke-теста на конкретной конфигурации.
