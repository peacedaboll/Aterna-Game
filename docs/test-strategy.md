# Стратегия тестирования

**Проект:** Aterna (Unity 2022.3.62f1, 2D) · **Версия документа:** 0.1 · **Дата:** 2026-10-09

Наличие автоматизированных тестов в проекте не подтверждено. На текущем этапе основа — ручные smoke- и regression-тесты.

## 1. Цели

1. Подтвердить, что проект открывается, собирается и запускается.
2. Проверить переходы: меню → выбор персонажа → выбор локации → уровень.
3. Проверить движение, прыжок, столкновения и анимацию.
4. Выявлять регрессии после изменений кода, сцен и настроек.
5. Не считать неподтверждённые платформы и конфигурации поддерживаемыми.

## 2. Уровни и подходы

| Уровень | Что проверяется | Подход |
|---|---|---|
| Статическая проверка | Ошибки компиляции, ссылки на компоненты, имена сцен, параметры Animator | Unity Console, Inspector, Build Settings |
| Модульное | Изолированная логика, вынесенная в тестируемые методы | Unity Test Framework (по мере развития) |
| Интеграционное | Совместная работа кнопок, сцен, физики, анимации | Ручная проверка в Editor и билде |
| Системное | Полный путь от запуска до игрового уровня | Сквозной сценарий |
| Регрессионное | Ранее работавшие функции после изменений | Повторный прогон обязательного чек-листа |
| Тестирование сборки | Создание и запуск standalone-версии | Сборка и проверка Windows-билда |
| Совместимости | ОС, разрешения, оборудование | [Матрица совместимости](compatibility-matrix.md) |

## 3. Критерии начала (Entry)

- Проект открывается в Unity 2022.3.62f1.
- Нет известных ошибок компиляции.
- Указана версия или commit проекта.
- Определены шаги сценария и ожидаемый результат.
- Нужные сцены включены в Build Settings.
- Для проверки standalone-версии сборка завершилась успешно.

Если сборка не создаётся, тестирование билда блокируется: отдельно проверяется запуск в Editor и регистрируется ошибка сборки.

## 4. Критерии завершения (Exit)

- Проверки P0 пройдены либо зарегистрирован блокирующий дефект.
- Основной путь от меню до игрового уровня проверен.
- Движение и прыжок проверены на земле и в воздухе.
- В Console нет необъяснённых ошибок проверяемого сценария.
- Standalone-билд запускается (если это входит в цель проверки).
- Все найденные дефекты зарегистрированы.
- В матрице совместимости только фактически проверенные конфигурации.

Если основной сценарий не работает, тестирование не считается успешно завершённым, даже если остальные проверки прошли.

## 5. Регистрация дефектов

| Поле | Описание |
|---|---|
| ID | `BUG-001`, `BUG-002`, … |
| Дата и версия | Дата, версия или commit |
| Окружение | Платформа и разрешение |
| Шаги | Шаги воспроизведения |
| Ожидание / факт | Ожидаемый и фактический результат |
| Серьёзность | Blocker / Critical / Major / Minor |
| Вложения | Лог или скриншот |
| Статус | Open / In Progress / Fixed / Retest / Closed |

Рекомендуется вести дефекты в GitHub Issues с метками `bug`, `blocker`, `critical`, `major`, `minor`.

## 6. Чек-листы ручного тестирования

Начальный статус всех пунктов — **Не проверено**. После прогона отмечать: Пройдено / Не пройдено / Заблокировано.

### 6.1. Smoke-тест
- [ ] Проект открывается в Unity 2022.3.62f1
- [ ] Нет ошибок компиляции в Console
- [ ] Главное меню запускается
- [ ] Start выполняет ожидаемый переход
- [ ] Exit работает ожидаемым образом
- [ ] Все нужные сцены есть в Build Settings
- [ ] Windows-билд собирается успешно
- [ ] Собранная игра запускается и показывает главное меню

### 6.2. Главное меню и настройки
- [ ] Меню отображается корректно
- [ ] Start открывает ожидаемый экран
- [ ] Exit не вызывает ошибок
- [ ] Окно настроек открывается и закрывается
- [ ] Каждая видимая настройка действительно работает
- [ ] Незавершённые функции не представлены как готовые
- [ ] После закрытия настроек пользователь возвращается на ожидаемый экран
- [ ] UI проверен при целевом разрешении

### 6.3. Выбор персонажа
- [ ] Сцена выбора персонажа открывается без ошибок
- [ ] Доступный персонаж отображается
- [ ] Персонажа можно выбрать
- [ ] После выбора открывается ожидаемая сцена
- [ ] В Console нет ошибок загрузки сцены
- [ ] Недоступный слот не выглядит как работающая функция
- [ ] Кнопка возврата работает (если предусмотрена)

### 6.4. Выбор локации и загрузка
- [ ] Сцена выбора локации включена в Build Settings
- [ ] Отображаются все три узла выбора
- [ ] Каждый доступный узел реагирует на выбор
- [ ] Выбор открывает соответствующую локацию
- [ ] Анимация загрузки завершается
- [ ] Нет бесконечного цикла загрузки
- [ ] После загрузки открыта именно выбранная сцена
- [ ] Повторный переход к выбору локации работает
- [ ] Недоступная локация не приводит к зависанию

### 6.5. Управление персонажем
- [ ] Движение влево
- [ ] Движение вправо
- [ ] После отпускания клавиш движение прекращается ожидаемо
- [ ] Прыжок по Space на земле
- [ ] Прыжок в воздухе невозможен
- [ ] После приземления прыжок снова доступен
- [ ] Столкновения с платформами корректны
- [ ] Персонаж не проваливается сквозь землю
- [ ] Касание боковой стены не позволяет прыгать в воздухе
- [ ] Управление восстанавливается после потери и возврата фокуса окна
- [ ] Нет `NullReferenceException` от Rigidbody2D или Animator

### 6.6. Анимация
- [ ] Animator назначен в Inspector
- [ ] Параметр `isRunning` существует и имеет тип Bool
- [ ] Беговая анимация включается при движении
- [ ] Беговая анимация выключается при остановке
- [ ] Переходы между состояниями не застревают
- [ ] Анимация не меняет коллизии нежелательным образом

### 6.7. Враг и препятствия
- [ ] Столкновение с врагом предсказуемо
- [ ] Столкновение не блокирует управление навсегда
- [ ] Поведение соответствует прототипу (ИИ и урон пока не реализованы)
- [ ] Интерфейс не обещает функций, которых ещё нет

### 6.8. Проверка сборки
- [ ] Выбрана правильная платформа
- [ ] В Build Settings все нужные сцены
- [ ] Сборка завершается статусом Success
- [ ] Полученное приложение запускается
- [ ] Основной сценарий проходит в билде, а не только в Editor
- [ ] После исправления дефект проверен повторно
- [ ] Выполнены связанные регрессионные проверки
